# Implementation status

This is a work in progress, not a production release. The foundation, routing shell, curriculum loading, Philippine calendar, settings, daily word/phrase quizzes, archive, basic progress, and a preliminary speaking workflow are implemented. Curriculum files remain untouched.

Before release: implement the full Grammar Academy, assessments, weekly and spaced reviews, saved vocabulary, achievements, persistent recordings and recording downloads/deletion, speaking targets/preparation timer, accessible feature fallbacks, backup and transactional restore, translation coverage, assessment paths, comprehensive tests, offline verification, install icons, and GitHub Pages deployment. The PWA configuration is preliminary. Browser media behavior has not been validated. Do not deploy as v1 until these are complete.
